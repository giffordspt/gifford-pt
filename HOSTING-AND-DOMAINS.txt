no server code. That's the cheapest and easiest kind of site to host. You do
NOT need expensive hosting or anything with "cPanel", PHP or WordPress.

    - Turn ON auto-renew so the domains don't expire and get snapped up.

-------------------------------------------------------------------------------
  PART 3 — CONNECTING YOUR DOMAIN TO THE HOST
-------------------------------------------------------------------------------

Once the site is uploaded (e.g. to Netlify) and the domains are bought, you tell
the domain to point at the host. This is done with "DNS records".

On Netlify:  Site settings -> Domain management -> "Add custom domain" ->
             type giffordspt.com -> Netlify shows you the DNS records to set.

On Cloudflare Pages: it's automatic if the domain is also at Cloudflare;
             otherwise you add a CNAME record they give you.

At your registrar you'll set records that look roughly like:
    Type    Name    Value
    A       @       (the IP the host gives you)          <- for the bare domain
    CNAME   www     your-site.netlify.app                <- for www.

The host's own instructions always show the EXACT values to paste — follow
those, they override the generic example above.

DNS changes can take anywhere from a few minutes to a couple of hours to go
live worldwide. Don't panic if it's not instant.


-------------------------------------------------------------------------------
  PART 4 — MAKING BOTH .COM AND .CO.UK WORK
-------------------------------------------------------------------------------

You own two names but you only want to maintain ONE website. So:

    - Pick a MAIN address, e.g. giffordspt.com
    - Set giffordspt.co.uk to REDIRECT to giffordspt.com (or vice-versa).

That way, whichever a visitor types, they land on the same site and you only
update it in one place.

Netlify:  add BOTH domains to the same site; set one as "primary" and Netlify
          auto-redirects the other to it. Zero effort.
Cloudflare: use a "Redirect Rule" (free) to forward one domain to the other.

Which should be main? For a UK personal trainer, giffordspt.co.uk signals "local"
and can help with UK Google results — but .com is more memorable/global. Either
is fine. I'd suggest .com as main with .co.uk redirecting to it, unless you're
purely targeting local UK clients, in which case flip it.


-------------------------------------------------------------------------------
  PART 5 — (OPTIONAL) EMAIL @giffordspt.com
-------------------------------------------------------------------------------

Free hosting does NOT give you email. If Jack wants hello@giffordspt.com:
    - Cheapest: Cloudflare Email Routing (FREE) — forwards
      anything@giffordspt.com to his normal Gmail. He can RECEIVE for free.
      To SEND from that address too, pair it with a free-ish tool or use...
    - Google Workspace (~£5/user/month) or Microsoft 365 — proper mailbox,
      send + receive, calendar, etc.
    - Many registrars also sell basic email for ~£1/month.
Remember to update the placeholder "hello@example.com" in the site's contact
section once the real address exists (it's marked with an EDIT comment in
index.html).


-------------------------------------------------------------------------------
  RUNNING / PREVIEWING THE SITE ON YOUR OWN COMPUTER (before it's live)
-------------------------------------------------------------------------------

You can open the site locally any time to preview changes:

    EASIEST: just double-click index.html in the gifford-pt folder — it opens
    in your browser. (Everything works this way except it's fine for previewing.)

    BETTER (behaves exactly like the real server), if you have Python installed:
        1. Open PowerShell.
        2. Run:  cd "C:\Users\harry\OneDrive\Desktop\poker_analyzer\gifford-pt"
        3. Run:  python -m http.server 4173
        4. Open your browser to:  http://localhost:4173
        5. Press Ctrl+C in PowerShell to stop it.

    If you have Node.js instead of Python, step 3 becomes:  npx serve .


-------------------------------------------------------------------------------
  STEP-BY-STEP QUICKSTART (the whole thing, start to finish)
-------------------------------------------------------------------------------

  1. Go to porkbun.com, search "giffordspt", buy giffordspt.com AND giffordspt.co.uk.
     Turn on domain privacy + auto-renew. (~£16 total for the year.)

  2. Go to netlify.com, make a free account.

  3. Drag the whole "gifford-pt" folder onto Netlify's upload box.
     -> Your site is instantly live at something like giffordspt.netlify.app.
     Check it looks right.

  4. In Netlify: Domain settings -> add giffordspt.com and giffordspt.co.uk.
     Netlify shows you the DNS records to enter.

  5. Log in at Porkbun -> DNS settings for each domain -> paste the records
     Netlify gave you.

  6. Set giffordspt.com as the primary domain in Netlify (it'll auto-redirect
     the .co.uk to it).

  7. Wait a little while for DNS to update, then visit giffordspt.com — done!

  8. Later: add Jack's photos to the assets/ folder and edit the placeholder
     text (search for the pencil "EDIT" markers in index.html — see README.md),
     then re-drag the folder onto Netlify to update the live site.
